TikTokVideoDirector

Privacy policy

Last updated: 3 October 2026

TikTokVideoDirector is an experimental local Windows application maintained through the Adrian22575 project repository. This page describes the application's implemented data flows; it does not claim that the TikTok integration has been approved.

Your work stays on your computer

The application stores project requests, scripts, decisions, captions, provider usage records, media and rendered files in a local SQLite database and local folders. It does not upload these projects to this website or operate a central project-storage service.

Providers you choose to use

In API generation mode, OpenAI receives the text and, for visual analysis, selected media frames needed for the requested AI task. ElevenLabs receives narration text and the selected voice identifier to generate speech. Pexels receives stock search queries and supplies footage. Those services handle requests under their own policies. Other test modes can reuse local resources; availability and provider use depend on the operation selected.

OpenAI Responses requests in this implementation use store:false. This is not a promise of zero retention by providers. Review OpenAI's policy, ElevenLabs' policy and Pexels' policy before using their services.

Optional TikTok connection

When approved and configured, TikTok authentication occurs on TikTok's own page. The application does not collect your TikTok password. The requested scopes are user.info.basic and video.upload. Basic profile access supplies your account identifier and display name so that you can confirm the destination of a transfer.

TikTok client secrets, authorization verifiers and account tokens are encrypted locally with Windows CurrentUser DPAPI. The application refreshes tokens on the server and does not send them to the application browser or this website. Connection records and transfer identifiers remain in the local database.

A video is transferred to TikTok only after you explicitly confirm the connected account and exact final file. The application keeps a local immutable copy for the transfer. It sends the MP4 through TikTok's Upload API; captions are copied separately. TikTok processes the transferred content under its privacy policy. Receiving a video in your inbox does not mean it has been published.

Control and retention

Disconnecting TikTok invalidates local authorization and pending work and attempts to revoke the remote token. It cannot retract a video TikTok has already received. You can also revoke access in TikTok's account settings.

Local project records, history, media and transfer snapshots remain until removed from the computer. Automatic cleanup of upload snapshots is not currently implemented. To remove all local application data, stop the application and worker, and remove its configured data directory and any backups. Keep any files you wish to retain. Revoking TikTok access does not delete content already held by TikTok.

This website

These static pages contain no analytics script, advertising, tracking pixel, sign-in form or custom cookie. They are hosted on GitHub Pages, whose infrastructure may process connection information such as IP addresses under GitHub's privacy statement.

Questions

Contact the maintainer through the project issue tracker. That tracker is public: do not include passwords, tokens, private footage or sensitive personal information. A private contact channel has not yet been established.
